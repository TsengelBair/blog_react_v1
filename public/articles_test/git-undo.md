## Отмена в Git

| Что | Команда |
|---|---|
| Отменить **незакоммиченное** | `git restore .` |
| Убрать из staging | `git restore --staged .` |
| Отменить **последний коммит** | `git reset --soft HEAD~1` |
| Отменить **коммит в истории** | `git revert <hash>` |

> `reset` — **переписывает** историю. `revert` — **добавляет** обратный коммит.
