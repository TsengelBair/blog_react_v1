### Убрать изменения из рабочей копии (уберет все локальные изменения)
```
git checkout -- .
```
Предварительно всегда используем `git diff`, чтобы увидеть все внесенные и недобавленные в индекс изменения

### Убрать изменения из индекса
Если случайно выполнил `git add` после внесения изменений, для того чтобы убрать их из индекса коммита
```
git reset
```
После этой команды внесенные изменения не пропадут, а останутся в рабочей копии и их можно убрать как обычно, просто сбросив текущую рабочую копию `git checkout -- .`

### Убрать последний локальный коммит со всеми изменениями в нем
Если случайно выполнил коммит, но не запушил - его можно убрать 
```
git reset --hard HEAD~1
```
Это полностью удалит последний коммит и все изменения в нем. Рабочая директория вернется в состояние до коммита.

`HEAD~1` означает откатись назад от текущего положения

К примеру если нужно убрать три последних коммита 
```
git reset --hard HEAD~3
```

### Убрать коммит, но сохранить изменения
Для того чтобы убрать коммит, но оставить изменения
```
git reset --soft HEAD~1
```
